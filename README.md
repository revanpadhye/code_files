# code_files
The Pickle Club is a court booking web app for the Nagpur pickleball club. Users can: log in / sign up book any of 4 courts (weekday ₹800/hr, weekend ₹900/hr) buy Membership or Elite Card pay with Razorpay (UPI / card / net banking) Built with FastAPI + HTML/JS/CSS, one server for both frontend and backend, SQLite database.
